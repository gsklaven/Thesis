# Interpretation notes on the results (for Chapter 5)

The numbers, tables and lists are generated by `results/results_analysis.py` (`<tag>.md`,
`confusion_<tag>.svg/.tex`, `ablations.md`) and `results/thesis_tables.py` (LaTeX of the thesis). This file
holds the observations and interpretation, which the scripts do not rewrite. The v14 runs are the final
results of the thesis (Chapter 5 is the full interpretation).

## v14 - the four configurations

- Full system (LLM stage, 442 malware / 343 benign with Behavior Chains): recall 96.8% [94.8-98.1],
  FPR 1.5% [0.6-3.4], precision 98.8%, F1 97.8%, accuracy 97.6%; end-to-end accuracy 97.1% (922/950).
- Without RAG: recall 95.5%, FPR 1.2%. Retrieval adds 6 detections for one extra false positive; the false
  positives of the full system and of the configuration without RAG are different packages (borderline cases).
- The four configurations agree on 96% of the malware and of the benign packages: the main signal is the
  Behavior Chain representation. Detected only with retrieval (all three RAG configurations): ansiicolor,
  kirux189894, piirgg, rblxtools - the nearest neighbour shows the same code in a known malicious package.
- No false positive on the 39 curated benign packages; the 5 false positives of the full system are among the
  304 sampled popular packages, each with a single flagged chain.
- Constant arguments: fabric (setup.py executes "_version.py") is BENIGN in every configuration, while
  set-utils uses the same exec(open(...).read()) pattern on "para/about.py" and is detected.
- Priority: ACT for 370/428 true positives of the full system; with an alert on ACT only, recall 83.7% at
  FPR 0.3%.
- Dependency check: dmclc (4 malicious declared dependencies, all in OSV and removed from PyPI) is caught in
  every configuration; no benign package or obfuscated copy is flagged.

## Obfuscation

- Natural: 140/442 malware decode and execute code; recall 96.4-97.9% on them vs 95.0-97.0% on the rest.
- Intensio-Obfuscator copies: malware level A 82-84/85 with chains (12 copies without chains, mostly files that
  are no longer valid Python), level B 95-97/97. Benign level A 14-30/78 flagged, 0/6 of the intact copies;
  level B 88-96/99 flagged - the model names the obfuscation itself (random identifiers, dead code, exec of
  encoded content) as the unexplained action. Retrieval raises the flags on obfuscated benign code (obfuscated
  malware in the index, obfuscation techniques in the knowledge base).
